# Neovim Configuration

モダンなNeovim設定（Lua）。IntelliJからの移行を意識した設計。

## Requirements

- Neovim >= 0.9
- JetBrainsMono Nerd Font（WezTermで設定済み）
- ripgrep, fd（Telescope用）
- lazygit（Git UI用）

```bash
brew install neovim ripgrep fd lazygit
```

## Quick Start

1. dotfilesのインストールスクリプトを実行してシンボリックリンクを作成
2. Neovimを起動: `nvim`
3. プラグインが自動インストールされる（初回は数分かかる）
4. `:Mason` でLSPサーバーをインストール

## Tips for Beginners

1. **which-keyを活用**: Spaceキーを押して待つとキーバインドが表示される
2. **モード意識**: Normal（操作）/ Insert（入力）/ Visual（選択）の3モードを意識
3. **hjkl移動**: 矢印キーよりhjklに慣れると効率的
4. **ドットコマンド**: `.` で直前の操作を繰り返せる
5. **`:Tutor`**: 内蔵チュートリアルで練習
6. **jk/jjでEscape**: 挿入モードで `jk` または `jj` を素早く入力するとノーマルモードに戻れる
7. **テキストオブジェクト**: `ciw`（単語変更）、`di"`（クォート内削除）など動詞+範囲の組み合わせを覚える

## よくある操作 FAQ

### Q: ファイルツリー（neo-tree）からファイルを開いた後、ツリーに戻るには？

| 方法 | キー | 説明 |
|------|------|------|
| 方法1 | `Ctrl+h` | 左のウィンドウ（neo-tree）にフォーカス移動 |
| 方法2 | `<Space>e` | neo-treeをトグル（開く/閉じる） |
| 方法3 | `<Space>o` | 現在のファイルをneo-treeで表示（ツリーにフォーカス移動） |

### Q: 上に表示されるタブ（バッファ）を閉じるには？

| キー | 操作 |
|------|------|
| `<Space>bd` | 現在のバッファ（タブ）を閉じる |
| `<Space>bD` | 強制的に閉じる（保存していなくても） |
| `Tab` | 次のバッファに切り替え |
| `Shift+Tab` | 前のバッファに切り替え |

### Q: ウィンドウ間を移動するには？

| キー | 移動先 |
|------|--------|
| `Ctrl+h` | 左のウィンドウ |
| `Ctrl+j` | 下のウィンドウ |
| `Ctrl+k` | 上のウィンドウ |
| `Ctrl+l` | 右のウィンドウ |

## 自動機能

この設定には以下の自動機能が含まれています：

- **ヤンク時ハイライト**: コピーした範囲が一瞬光る
- **最後の位置に移動**: ファイルを開くと前回の編集位置にカーソルが移動
- **ディレクトリ自動作成**: 存在しないディレクトリにファイルを保存すると自動作成
- **ファイル変更検知**: 外部で変更されたファイルを自動で再読み込み
- **末尾空白削除**: 保存時に行末の余分な空白を削除（設定で無効化可能）

| キー | 機能 |

### 自動機能

- Normal モード: リッチな装飾表示（見出し背景色、アイコン等）

- 画像: カーソル位置の画像をインライン表示（Wezterm 必須）

```

```
